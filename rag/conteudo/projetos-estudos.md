# Projetos de estudo do Bruno (Django, PHP, Java e Flutter)

## Revenda de carros com Django

O revenda-de-carros_DJANGO é um projeto de estudo do Bruno Romeu da Silva feito durante o curso Django Master. É um sistema de gestão de uma revenda de carros com CRUD de carros, upload de imagens, autenticação de usuários (login e logout) e uma interface básica de administração, usando Python, Django, SQLite e templates HTML e CSS. Com ele Bruno praticou models, views, URLs, templates e arquivos estáticos e de mídia.

## Projetos em PHP do início dos estudos

No início dos estudos, Bruno Romeu da Silva fez projetos em PHP a partir de cursos livres: uma agenda de contatos com CRUD completo, um blog sem banco de dados externo e o MovieStar, uma rede social de críticas de filmes com cadastro, login e avaliações. Bruno também fez uma API em PHP puro com padrão DAO, com endpoints de cadastro, login, cidades e avaliações de cidades. Esses projetos estão no GitHub do Bruno.

## Java e Flutter nos estudos do Bruno

Na disciplina de Programação Orientada a Objetos da faculdade, Bruno Romeu da Silva fez exercícios em Java, de programas de console a janelas com JOptionPane, e um sistema de gerenciamento de veículos com classes abstratas, herança, encapsulamento e polimorfismo. Bruno também fez primeiros testes com Flutter, como um app de lista de tarefas. Java e Flutter são estudos do Bruno, não fazem parte da stack principal dele.
