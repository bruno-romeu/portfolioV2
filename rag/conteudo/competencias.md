# Competências técnicas e stack do Bruno

## Linguagens de programação que o Bruno usa

As linguagens que Bruno Romeu da Silva lista no currículo são TypeScript, JavaScript, PHP, Python, SQL, HTML e CSS. No trabalho como Desenvolvedor Fullstack na Infinilabs, Bruno usa quase sempre Python e TypeScript. PHP aparece nos projetos com Laravel, e SQL no trabalho com PostgreSQL e MySQL. Na faculdade, Bruno também praticou Java na disciplina de Programação Orientada a Objetos.

## Frontend: frameworks e bibliotecas do Bruno

No frontend, Bruno trabalha com Next.js, React, Astro, Tailwind CSS, shadcn/ui e Bootstrap. Bruno usa React com TypeScript em vários projetos, como este portfólio (React, Vite e Tailwind CSS) e o frontend do Sinaliza, seu TCC. Em projetos pessoais com Laravel, como o CineDash e o SGE Laravel, Bruno também usou React com Inertia.js para ligar o frontend ao backend.

## Backend: frameworks e autenticação do Bruno

No backend, Bruno trabalha com NestJS, Laravel, Django e Django REST Framework, além de autenticação com Passport e JWT. Em projetos pessoais, Bruno também usou FastAPI, por exemplo no Sinaliza (seu TCC), na automação de conteúdo para Instagram e no bot de finanças pessoais via WhatsApp. Bruno costuma construir APIs, regras de negócio, autenticação e integrações com APIs externas.

## Banco de dados e ORM do Bruno

PostgreSQL é o banco de dados principal do Bruno. Ele também trabalha com MySQL e usa os ORMs Prisma, Eloquent (Laravel) e Django ORM. Em projetos Python com FastAPI, Bruno usou SQLAlchemy com migrations versionadas pelo Alembic. Bruno dá atenção à modelagem de dados: na Infinilabs, fez a modelagem e a documentação dos dados de uma plataforma, com diagrama de entidades.

## DevOps, CMS e ferramentas do Bruno

Em DevOps, Bruno usa Docker, Docker Compose e GitHub Actions. Como CMS, Bruno trabalha com Strapi. As ferramentas do dia a dia do Bruno são Git, GitHub, pnpm, Turborepo e Postman. Nos projetos pessoais, Bruno sobe as aplicações com Docker Compose e usa GitHub Actions para integração contínua, como no Sinaliza e na automação de conteúdo para Instagram. Bruno também participou da configuração do deploy de uma plataforma na Infinilabs.

## IA e produto: competências do Bruno

Em IA, Bruno trabalha com desenvolvimento assistido por agentes e com integração de APIs de IA em aplicações, como fez com a API Gemini em projetos pessoais e com o chat RAG deste portfólio. Em produto, Bruno faz levantamento de requisitos, prototipação, modelagem de dados e planejamento de sprints. Na Infinilabs, Bruno usou essas competências de produto como principal responsável por uma plataforma de adequação à NR-1.
