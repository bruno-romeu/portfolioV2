# Projeto CineDash

## O que é o CineDash

O CineDash é um projeto pessoal do Bruno Romeu da Silva: uma plataforma social para organizar, avaliar e compartilhar filmes, inspirada no visual de plataformas de streaming e em trackers de filmes. No CineDash o usuário adiciona filmes a uma watchlist, marca como assistidos e dá notas, vê o que os amigos estão assistindo em um feed e acompanha estatísticas de perfil, como tempo assistido, média de notas e gêneros favoritos. A interface é escura e responsiva.

## Stack do CineDash

O CineDash, do Bruno, foi construído com Laravel 11 no backend e React 18 no frontend, ligados pelo Inertia.js, sem precisar criar uma API REST manual. A estilização é com Tailwind CSS, os ícones com Lucide React e as animações com tailwindcss-animate. O projeto mostra o Bruno trabalhando com o ecossistema Laravel e com frontend em React. O código está em github.com/bruno-romeu/cinedash.
