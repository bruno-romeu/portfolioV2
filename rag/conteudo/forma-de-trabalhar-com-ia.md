# Como o Bruno trabalha com desenvolvimento assistido por IA

## Base tradicional antes da IA

Bruno Romeu da Silva construiu uma base sólida em desenvolvimento tradicional escrevendo código sem apoio de IA, em cursos livres, na faculdade de Análise e Desenvolvimento de Sistemas e em projetos pessoais. Hoje boa parte do código do Bruno é escrita junto com agentes de IA, mas essa base é o que permite a ele entender, validar e corrigir o que a IA produz.

## O fluxo do Bruno com agentes de IA

Para o Bruno, o que importa é fazer desenvolvimento assistido por IA direito. O fluxo dele tem quatro pontos: especificação antes de começar, decisão registrada, teste rodando contra o sistema real e revisão antes do merge. Bruno trabalha com um fluxo estruturado de contexto, validação e revisão de código, em vez de aceitar o código gerado sem verificação.

## IA no time da Infinilabs

Na Infinilabs, Bruno participou da definição do fluxo de desenvolvimento assistido por IA da equipe. O fluxo usa contexto de projeto documentado, para que os agentes trabalhem com as informações certas do projeto, e revisão de código em pull requests. É um exemplo de como Bruno aplica a mesma disciplina de especificação e revisão no trabalho em equipe.

## Exemplo prático: documentação e decisões no Sinaliza

O Sinaliza, TCC do Bruno, mostra na prática como ele organiza um projeto feito com apoio de IA. O repositório tem um arquivo de regras do projeto para agentes (AGENTS.md), documento de requisitos funcionais e não funcionais, decisões de arquitetura, modelo de dados e registros de decisão. O código cita os identificadores de requisitos e de arquitetura, e há testes automatizados no backend e no frontend rodando em CI.

## Integração de IA dentro dos produtos

Além de usar IA para desenvolver, Bruno integra APIs de IA em aplicações. Neste portfólio, ele construiu um chat com RAG que responde sobre a trajetória dele. Em projetos pessoais, Bruno usou a API Gemini para sugerir melhorias em catálogo de e-commerce e para gerar e classificar conteúdo em uma automação para Instagram. No Sinaliza, experimentou um pipeline de Machine Learning com scikit-learn, mantido fora da interface.
