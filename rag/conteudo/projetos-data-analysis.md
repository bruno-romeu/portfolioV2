# Projeto de análise de dados de vendas (data_analysis)

## Análise exploratória de vendas de e-commerce

O data_analysis é um repositório de estudos do Bruno Romeu da Silva em análise de dados com Python. O projeto principal é uma análise exploratória de transações de vendas de um e-commerce, feita em Jupyter Notebook com Pandas e Matplotlib. A análise identifica o melhor mês de vendas, as vendas por gênero e por faixa etária e a categoria de produto mais vendida em cada grupo, com gráficos de barras para cada métrica. O código está em github.com/bruno-romeu/data_analysis.
