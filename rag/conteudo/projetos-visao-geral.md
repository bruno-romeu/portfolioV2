# Visão geral dos projetos públicos do Bruno no GitHub

## Principais projetos pessoais do Bruno

Os principais projetos pessoais públicos do Bruno Romeu da Silva no GitHub (github.com/bruno-romeu) são: o Sinaliza, seu TCC, um sistema de apoio ao acompanhamento da trajetória escolar com FastAPI, PostgreSQL e React; uma automação de conteúdo para Instagram com FastAPI, PostgreSQL e Gemini; e este portfólio (portfolioV2), com um chat de IA baseado em RAG. Esses projetos mostram o Bruno trabalhando com backend, frontend, dados, infraestrutura com Docker e integração com IA.

## Outros projetos do Bruno por área

Além dos principais, o GitHub do Bruno tem projetos por área. Em Laravel com React e Inertia.js: o CineDash, plataforma social de filmes, e o SGE Laravel, de gestão de estoque. Em Django: a Flix API, API RESTful de filmes, e um sistema de revenda de carros. Em dados e automação com Python: o ETL-ecommerce com Gemini, o bot comparador de preços com Selenium e Streamlit, o bot de finanças pessoais via WhatsApp e uma análise exploratória de vendas com Pandas.

## Projetos de estudo do Bruno

O GitHub do Bruno também guarda projetos de estudo do início da formação: aplicações em PHP de cursos livres (agenda de contatos, blog e rede social de críticas de filmes), uma API em PHP com padrão DAO para avaliações de cidades, exercícios de Programação Orientada a Objetos em Java da faculdade e primeiros testes com Flutter. Os projetos do trabalho na Infinilabs são de clientes e não estão públicos no GitHub do Bruno.
