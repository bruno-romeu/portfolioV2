# Projeto Flix API (Django REST Framework)

## O que é a Flix API

A Flix API é uma API RESTful de filmes desenvolvida pelo Bruno Romeu da Silva com Python, Django e Django REST Framework, como parte do curso Django Master. A API oferece os endpoints para um frontend web ou mobile gerenciar usuários, catalogar filmes e controlar o que cada usuário já assistiu, o que quer assistir e seus favoritos. Em desenvolvimento, usa SQLite. O código está em github.com/bruno-romeu/flix-API-Django.

## Funcionalidades da Flix API

A Flix API, do Bruno, tem registro e login de usuários com autenticação por tokens, CRUD completo de filmes, listas de favoritos e de filmes desejados para usuários autenticados, e endpoints de busca e filtragem de filmes por título e outros critérios. O projeto foi a forma do Bruno praticar models, serializers, endpoints e organização de uma aplicação backend com Django REST Framework.
